# yt-dlp 版本检查与组件更新

在「设置 → 工具与更新」查看当前安装版本、系统与架构，以及自动选择的安装包。例如 Windows x64 对应 `yt-dlp.exe`，Windows ARM64 对应 `yt-dlp_arm64.exe`，Linux x64 / ARM64 分别对应 `yt-dlp_linux` / `yt-dlp_linux_aarch64`。不支持的平台会明确报错，不尝试安装其他架构。

点击「检查 yt-dlp 更新」会查询所选官方稳定版或 nightly 通道，显示本地版本、GitHub 最新版本和是否可更新。检查不安装组件，也不替换现有文件；本地比所选通道新时会明确说明。版本检查失败不会显示“已是最新”。Docker 界面也可以检查远端稳定版，但容器中的组件仍随镜像更新。

桌面安装可选择下载来源：

- **自动**：先从 GitHub 下载，连接失败、HTTP 错误、超时或完整性校验失败后，使用第三方 CDN `ghfast.top`。自动模式中第一次直连请求最多等待 30 秒。
- **GitHub 直连**：只访问官方安装包。
- **第三方 CDN**：通过 `ghfast.top` 中转安装包下载。

版本输入留空会先解析官方最新标签，再下载固定标签对应的安装包；输入完整标签则下载该版本。CDN 缓存的其他版本无法通过预期版本的 SHA-256 校验。下载与更新失败保留当前组件，版本及必需参数兼容性检查通过后才切换当前组件。

SHA-256 校验文件始终从官方 GitHub HTTPS 获取，不从第三方 CDN 获取。GitHub API 限流不会阻止通过官方发布跳转查询版本，也不会消耗该 API 配额；但官方发布站或其校验文件本身完全无法访问时，会停止安装并显示原因。CDN 的可用性和速度取决于其服务及当前网络。第三方只接收公开安装包 URL，不接收下载任务的 Cookie、代理凭据或个人媒体 URL。

已加入任务继续使用冻结的工具和身份配置；更新只影响新任务。要使用新版本，请重新添加原始视频链接。
