# MCP 实施验证（2026-10-16）

本记录对应 `main` 上的 MCP 实现，协议使用官方 rmcp 3.5.1。连接与工具说明见 [MCP.md](MCP.md)。MCP 默认关闭；启用后由单个开关控制资料查询和下载管理，不使用访问令牌。Docker 管理页为 `/mcp`，协议地址为同源 `/mcp-server`。

## 已完成

- 10 个明确参数的工具：搜索、视频资料、格式、合集、字幕文本、YouTube 评论、创建下载、下载列表、单项状态、暂停/继续/取消/重试。
- 桌面本机 Streamable HTTP、stdio 桥接程序和 Docker 同端口 Web MCP；Host/Origin 校验保留，管理开关仍使用 Web 登录和 CSRF。
- MCP 复用保存的 Cookie、代理、下载设置和现有队列，不创建第二个下载器实例；不会返回 Cookie 原文、代理密码、内部目录或签名媒体直链。
- 字幕轨道发现支持人工和自动字幕，解析 JSON3、VTT 和 SRT；合集公开链接保留 B 站 `p` 分 P 标识；不支持上游有界评论的站点会明确拒绝，避免先抓完整评论再截断。
- Docker 关闭 MCP 时取消当前 MCP 会话与在途查询，已入队下载不受影响；重新开启使用新的会话生命周期。
