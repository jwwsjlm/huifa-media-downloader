# 0.2.0

- 将下载业务迁移到 Rust，Windows 与 Linux 桌面界面采用 Tauri 和 React。
- 桌面与 Docker 网页使用同一份下载界面；Docker 映射 19491 端口，提供账号密码登录、Cookie 导入及远程浏览器登录。
- 下载与本地处理分别排队，保留格式选择、批量和合集、字幕、多音轨、章节、裁切、转码及音频导出能力。
- 提交任务时固定处理选项和工具版本，保存本地输入及处理记录，支持处理失败后的离线重试和重启恢复。
- 保留封面工作室、JPEG 导出和 AI 原图编辑；Cookie 与 AI 密钥加密保存。
- 调整界面层级、间距、字体和对比度，增加圆角分组，改进深浅色主题及窄窗口布局。
- 新版本使用独立安装标识和数据目录，旧版本安装和数据保持原样；视频发布相关功能暂时屏蔽。
- 通过 GitHub Actions 统一发布 Windows 安装包、Linux AppImage 和 Docker amd64／ARM64 镜像，提供校验文件及签名桌面更新。
- 移除当前代码树中的旧 Python、Qt 和 Electron 实现及打包脚本，历史实现仍可从 Git 找回。
