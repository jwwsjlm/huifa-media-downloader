# Huifa Media Downloader 0.1.3

## 中文

- 应用更新流程统一为 Velopack，便携版和安装版共享完整目录更新机制，不再依赖旧的单 EXE 更新链路。
- GitHub 更新仓库固定为官方项目地址，更新检查和下载不再受本地设置中的仓库地址影响。
- 更新窗口直接读取对应 GitHub Release 标签的发布说明，能够准确展示当前目标版本的更新内容。
- 发布页面继续提供便携版 ZIP 与安装包 ZIP 的直接下载入口，并包含自动更新需要的完整包、版本元数据和 SHA-256 校验文件。
- 桌面端发布功能改为结构化参数直接调用，减少命令行参数生成与重复解析带来的错误和额外开销。
- 精简中英文语言包及不可达的旧第三方上传代码，同时保留界面所需的二维码登录显示能力。
- 移除 OpenCV、Segno 和 Loguru 等不再需要的运行依赖，缩小依赖范围并降低打包与启动复杂度。
- 完善发布脚本、开发文档和更新相关测试，提高便携版、安装版及后续自动更新的稳定性。

## English

- Application updates are now fully unified on Velopack. Portable and installed editions share the same complete-directory update mechanism, and the legacy single-EXE update path has been removed.
- The GitHub update repository is fixed to the official project address, so update checks and downloads no longer depend on a locally configured repository URL.
- The update dialog now reads release notes directly from the matching GitHub Release tag, ensuring that it displays the notes for the exact target version.
- GitHub Releases continue to provide direct download links for both the portable ZIP and installer ZIP, together with the full update package, version metadata, and SHA-256 checksums.
- Desktop publishing now invokes the publishing service with structured parameters, avoiding command-line generation and redundant argument parsing.
- The language packs and unreachable legacy third-party upload code have been reduced while preserving QR-code sign-in display in the application interface.
- Unused OpenCV, Segno, and Loguru runtime dependencies have been removed, reducing packaging and startup complexity.
- Release scripts, development documentation, and update-focused tests have been improved for more reliable portable, installed, and automatic-update flows.
