# Huifa Media Downloader 0.1.14

## 中文

- 修复安装向导未显示自定义安装路径页面的问题；所选目录会正确传递给内部安装组件。
- 修复安装版错误写入系统目录的问题：设置、数据库、更新状态等改存到当前用户的 AppData\Local；便携版仍保留随程序目录保存的方式。

## English

- Fixed the installer wizard so the custom installation-folder page is shown and the selected folder is passed to the internal installer.
- Fixed installed-edition writable data storage: settings, database, and update state now use the current user's AppData\Local; portable builds still keep data beside the app.
