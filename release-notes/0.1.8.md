# Huifa Media Downloader 0.1.8

## 中文

- 全面优化明暗主题，统一字体、间距、卡片、表单、按钮及焦点、按压、禁用状态，提升界面层次和可读性。
- 精简任务默认选项的持久化数据，并使用 SQLite 批量更新，降低大量任务场景下的内存、序列化和数据库开销。
- 关机恢复只更新数据库中仍存在的任务，避免已删除任务被意外写回。
- 普通代码推送不再自动运行 GitHub Actions；发布版本 tag 时会执行完整测试、打包和发布流程。

## English

- Refined the light and dark themes with consistent typography, spacing, cards, form controls, buttons, and focus, pressed, and disabled states.
- Reduced task persistence size and database overhead through sparse default options and batched SQLite updates.
- Limited shutdown recovery to tasks that still exist in the database, preventing deleted tasks from being written back.
- Stopped GitHub Actions from running on ordinary pushes; version tags now run the full test, package, and release pipeline.
