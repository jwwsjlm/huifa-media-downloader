# Huifa Media Downloader 0.4.1

## 改进
- 网站登录直接显示在网络设置页，无需中间弹窗；Cookie 自动保存并按目标网站使用，无需命名或选择记录。
- 内置浏览器新增地址栏、返回、前进和刷新，记住上次使用的网址与登录方式；导航栏与网站页面保持权限隔离。
- 删除任务时自动记住“同时删除媒体文件”的选择，取消删除也保留偏好；设置写入失败会显示原因。
- 中英文 README 同步更新登录、设置保存与 Docker Compose 使用说明。

## 修复
- 登录 Cookie 最后一次同步失败时仍可关闭浏览器，保留此前已保存的身份；新任务可继续使用已保存 Cookie 或匿名访问。
- 修复抖音短链 Cookie 域名匹配和无需名称的 Cookie 兼容，内置 yt-dlp 抖音提取器兼容修复。
- 修复普通设置、MCP 配置与界面偏好同时保存时旧草稿覆盖新配置的问题。
- 修复 Linux 长中文标题导致临时发布文件名超出文件系统限制的问题，保留中断恢复与文件归属校验。

## 下载与部署
- 提供 Windows 安装版、签名便携 ZIP、Linux AppImage，以及 Docker linux/amd64 和 linux/arm64 镜像。
- Docker 镜像：`ghcr.io/jwwsjlm/huifa-media-downloader:0.4.1`。Compose 中数据与下载映射使用 `./data` 和 `./downloads`。
- 保留现有配置、任务和 Cookie。Docker 升级执行 `docker compose pull` 和 `docker compose up -d`，不要删除原有数据卷。
- 站点能力仍取决于 yt-dlp 和网站实际响应；抖音兼容补丁对应上游 PR #17826，网站变更可能影响可用性。

## 验证
- 本地通过 Rust、前端、Clippy、类型检查及 Windows 构建；Windows 原生浏览器使用独立测试配置验证导航、持久化、弹窗、Cookie 范围及权限隔离。
- 正式发布流程另行检查 Windows／Linux 下载与处理、Docker 双架构持久化和认证，并校验及签名发布产物。
