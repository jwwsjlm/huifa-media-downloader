## 下载与任务显示改进

- 新增“无字幕时继续下载”，默认开启。所选字幕不存在时跳过缺失语言并继续下载视频，不弹出要求调整；关闭后仍严格检查字幕要求。设置、快速选项和 MCP 共用此选项。
- 任务列表在“已完成”旁显示本地完成日期和时间，精确到分钟。可在“设置 → 外观与封面 → 完成时间格式”自定义 YYYY-MM-DD HH:mm、YYMMDD HH:mm 等格式，并保存到磁盘。
- 旧任务从已有完成日志恢复时间；没有记录时留空。重新下载和转换会清空上次完成时间，新结果保存后重新记录。
- 错误提示改为简短的中文说明和处理建议，原始 yt-dlp 参数、输出及错误保留在“查看日志”中；补充 TLS、目录权限及设置校验提示。
- 重新设计“磁盘与缓存”：三项磁盘空间并排，缓存统计与清理按钮集中排列，窄窗口自动换行，减少多余留白。
- 同步中英文界面及 Docker、MCP 使用说明。

## Download and interface improvements

- Continue when subtitles are unavailable is enabled by default. Missing requested subtitle languages are skipped while the video continues. Turn it off to require all selected languages. Settings, quick options and MCP share the option.
- Completed task rows show the local completion date and time to the minute. Customize and save the format under Settings → Appearance & covers → Completion time format.
- Older tasks recover completion timestamps from recorded completion events when available. New downloads and conversions record their own completion time.
- Error messages show concise localized guidance. Original yt-dlp diagnostics remain in View logs. TLS connection, folder-permission and validation errors have clearer guidance.
- Storage and cache now uses a compact responsive layout with grouped volume statistics and cache actions.

TLS 连接异常仍需检查网络和下载代理；本次更新未保证解决来源网站或网络线路故障。修改代理后，已有任务请使用“使用当前设置重试”。

TLS failures can still require network or proxy troubleshooting. Use Retry with current settings for existing tasks after saving proxy changes.

如需降回旧版本，请关闭程序并恢复升级前备份；旧版本可能不识别新增的下载选项。To downgrade, close the app and restore the pre-upgrade backup; older versions may not recognize the new download option.
