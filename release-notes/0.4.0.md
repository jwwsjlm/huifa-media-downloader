# Huifa Media Downloader 0.4.0

## 新增与改进

- 桌面内置登录浏览器，并支持 Edge、Chrome、Chromium 本机浏览器登录。登录 Cookie 自动保存，按目标网站匹配，新任务无需手动选择身份；已有任务保留原快照。
- Cookie、代理和 AI 密钥改为本地明文文件，旧加密数据自动迁移；设置可查看已保存 Cookie 的域名、数量和同步时间。
- 自动画质下单视频直接入队，真正的合集才选择项目；增加剪贴板下载、字幕语言与人工优先选项，分片并发默认 4、推荐 6、最高 8。
- 下载判重覆盖界面、批量、合集和 MCP。同一来源复用任务记录，新结果验证成功后才替换旧文件；目录不再添加短任务编号。
- 任务显示实际工序编号，提供右键操作、复制视频名／来源／桌面完整路径，以及本地封面预览和更稳定的速度显示。
- 格式转换先选 MP4、MKV、MOV 或 WebM，自动优先换封装、必要时转码，保留原文件。AI 封面设置支持获取模型列表。
- MCP 整理为 28 个多站点工具，增加引擎发现、搜索来源、链接识别、方案预览、合集下载、附件保存和媒体转换，保留原工具调用兼容性。
- 新增 MCP 独立自启动设置、共用访问密码修改和版本检查；HTTP 首次默认账号／密码为 admin/admin，改密后持久保存并撤销旧会话。
- 统一控件尺寸、间距、中英文文案与窄窗口布局；中英文 README 增加可直接部署的 Docker Compose 和升级说明。

## 修复

- 防止删除失败附件任务时误删同名用户文件；恢复未完成发布并清理受管临时文件及备份。
- 保留文件删除任务后，媒体仍可转换，重新添加原链接可复用记录。
- 直播分离音视频同时录制，任一路失败后取消并等待同组进程退出；修复全部音轨遗漏合并流中的语言。
- SponsorBlock 请求与响应体支持取消、超时和大小限制；HLS 点播不再误判为直播。
- 修复网页端单独修改 MCP 自启动失败；Web 与 MCP 共用认证失败限额，成功认证不消耗额度，请求断开仍记录失败。

## Docker 部署

镜像：`ghcr.io/jwwsjlm/huifa-media-downloader:0.4.0`，支持 linux/amd64 和 linux/arm64。完整 Compose 示例见仓库 README。保留原有数据卷，先执行 `docker compose pull`，再执行 `docker compose up -d`；不要使用 `down -v` 删除数据。

## 兼容与验证

- 原有配置、Cookie 和任务保留；历史下载目录不批量迁移。升级前建议备份数据目录或 Docker 数据卷。
- Cookie 和登录浏览器配置包含本地登录信息。网页登录和 MCP 共用访问密码，向其他设备开放服务前修改默认密码；AI 客户端使用 `Authorization: Bearer <访问密码>`。
- 站点解析由 yt-dlp 提供，字幕、评论、直播和搜索取决于提取器及网站实际能力。未逐站验证真实账号或公网直播。
- 本地已通过 Rust 140 项测试、前端 123 项测试、Clippy、Windows 构建、Linux 编译及 Docker 下载／转码／浏览器验收；正式产物另由发布流水线验收和签名。
