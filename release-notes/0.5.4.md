## 更多系统与处理器支持

- 新增 Apple 芯片和 Intel 芯片的 macOS 15 及以上桌面版，提供 DMG 下载和应用更新包。
- 新增 Windows ARM64 安装版、便携版及 Linux ARM64 AppImage，保留原有 Windows/Linux x64 版本。
- 为各平台随包提供经过来源、校验和及处理器架构检查的下载、媒体处理和 JavaScript 运行时组件。
- 发布说明增加按系统和处理器选择下载包的指南与直接下载链接，区分安装包、便携包和更新校验文件。
- macOS 网站登录使用本机 Chrome、Edge 或 Chromium，自动同步登录 Cookie。macOS 包使用临时签名，尚未经 Apple 公证；首次打开可能需要在“系统设置 → 隐私与安全”中允许打开。

## More platforms and processor architectures

- Added macOS 15+ desktop builds for Apple Silicon and Intel Macs, with DMG downloads and application update archives.
- Added Windows ARM64 installers and portable ZIPs, plus Linux ARM64 AppImages, alongside the existing Windows/Linux x64 builds.
- Bundled download, media-processing and JavaScript runtimes are checked for their source, checksum and processor architecture.
- Release notes now include a platform and processor selection guide with direct download links, distinguishing user downloads from update and integrity files.
- macOS website sign-in uses locally installed Chrome, Edge or Chromium with automatic cookie sync. macOS builds are ad-hoc signed and are not Apple-notarized; first launch may require permission under System Settings → Privacy & Security.
