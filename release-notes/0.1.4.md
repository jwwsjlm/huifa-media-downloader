# Huifa Media Downloader 0.1.4

## 中文

- 修复聚合链接解析条目时调用错误数据库接口导致程序异常的问题。
- 修复“智能解析并选择”模式中第一批合集条目被重复追加，造成数量和列表行数翻倍的问题。
- 修复退出软件时合集列表的延迟界面信号仍可能访问已关闭数据库的问题。
- 增加真实数据库回归测试，覆盖合集条目的流式写入、分页读取、后续批次追加及退出清理。
- 完善界面层与数据库、下载服务之间的接口契约检查，降低方法重命名后遗漏调用的风险。

## English

- Fixed an application error caused by the collection parser calling an invalid database interface while streaming entries.
- Fixed the first batch of collection entries being appended twice in “Parse and select” mode, which doubled the displayed count and rows.
- Fixed delayed collection-view signals potentially accessing the database after it had been closed during application shutdown.
- Added real-database regression coverage for streamed collection writes, paged reads, subsequent batches, and shutdown cleanup.
- Improved interface contract checks between the UI, database, and download service to reduce missed call sites after method changes.
