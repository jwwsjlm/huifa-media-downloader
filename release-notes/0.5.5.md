## 视频压缩与 FFmpeg 版本选择

- 已完成的本地视频可通过右键菜单压缩为独立任务和文件，原视频保持不变。简单模式按目标大小压缩，高级模式支持调整视频码率、缩小分辨率和降低帧率。
- 新增实际 GPU 编码能力检测和“GPU 编码加速”选项。GPU 处理失败后可改用 CPU 重试；不支持的像素格式、HDR 或轨道组合会明确阻止，不静默降低规格或丢弃轨道。
- 压缩默认使用 HEVC/MKV，校验完整时长及音轨、字幕、附件、章节和可支持的 HDR；简单模式只发布不超过目标大小的结果。
- 设置新增 FFmpeg“兼容优先（默认）／效率优先”和指定官方版本标签安装。按系统选择组件，FFmpeg 与 FFprobe 成对校验和安装；已有任务保留原工具，新压缩任务使用当前组件。
- Windows x64 的兼容构建调整为 FFmpeg 7.1.3，已通过 GTX 1080 Ti 实际编码验证；macOS、Windows ARM64 和 Linux 使用各平台对应的固定兼容构建。
- macOS 随包的 CPU x265 编码器目前仅支持 8 位。无法保留 10 位视频或 HDR 的编码路径会禁用并说明原因，原文件保留。
- macOS 版仍需 macOS 15 及以上，使用临时签名且尚未经 Apple 公证；首次打开可能需要在“系统设置 → 隐私与安全”中允许打开。

## 文件状态、下载与性能

- 外部删除视频后保留任务和历史，列表显示“不存在源文件”；文件恢复后自动恢复可用状态。权限不足或磁盘离线显示“暂时无法访问”，只检查当前可见记录和详情。
- 桌面设置新增剪贴板链接自动下载，默认关闭；保存启用后按当前下载设置识别链接，并保留合集和手动格式的确认流程。
- 普通下载断流后增加有限次数的自动重试并尽量续传，保留取消能力；改善重试和直播任务的进度同步。
- 减少队列调度及任务历史读取中的重复数据库查询。

## Compression and FFmpeg version selection

- Compress completed local videos into separate tasks and files. Simple mode targets a maximum file size; advanced mode supports bitrate, smaller dimensions and lower frame rates. Original videos are preserved.
- Added real GPU encoder capability checks and explicit CPU retry after GPU failures. Unsupported pixel formats, HDR and track combinations are rejected instead of silently reducing features.
- HEVC/MKV compression verifies duration, audio, subtitles, attachments, chapters and supported HDR. Simple mode publishes only results within the requested size limit.
- Added Compatibility (default), Efficiency and exact official release tags under FFmpeg settings. FFmpeg and FFprobe are verified and installed together for each platform. Existing tasks retain their tools; new compression tasks use the current components.
- The Windows x64 compatibility build uses FFmpeg 7.1.3 and has passed real GTX 1080 Ti encoding. Other platforms use their corresponding pinned compatibility builds.
- The bundled macOS CPU x265 encoder currently supports 8-bit output only. Encoder paths that cannot preserve 10-bit video or HDR are disabled with an explanation; source files are preserved.
- macOS builds still require macOS 15+, use ad-hoc signing and are not Apple-notarized. First launch may require permission under System Settings → Privacy & Security.

## File status, downloads and performance

- Missing files keep their task history and recover automatically when restored. Permission errors and offline storage show a temporary access failure. Checks cover visible rows and open details.
- Added optional desktop clipboard link monitoring, disabled by default, using the current download settings and existing collection/format confirmations.
- Added bounded retries with partial-file continuation after ordinary download interruptions, and improved retry/live progress updates.
- Reduced repeated database queries during queue scheduling and task-history reads.
