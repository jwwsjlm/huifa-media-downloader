## 应用内更新

- 桌面版启动完成后自动检查更新；侧栏、关于页和设置页共享更新状态，切换页面时下载继续。
- 点击“下载更新”后显示下载与签名验证进度，验证完成后由你选择“重启并安装”。不自动下载或自动安装。
- 完整更新包保存在本地。退出后重新打开会先联网核对更新清单，匹配并重新验证后直接恢复待安装状态。
- 安装前停止后台工作、保存任务进度并备份配置；保存或备份失败时中止安装，并提示关闭后重新打开。

## Windows 便携版与稳定性

- Windows x64 / ARM64 便携版可下载签名 ZIP，退出后由辅助进程替换程序和随包组件，再自动启动新版。
- 替换失败时恢复旧文件，异常中断后可再次打开恢复；保留用户文件及工具目录中的自定义文件。
- 按 Windows 大小写规则识别受管组件，避免旧文件覆盖已验证的新组件；更新完成后的临时文件占用不会阻止应用启动。
- 更新清单覆盖六个安装版平台和两个 Windows 便携版目标，并保留旧客户端使用的安装版目标。

## 升级说明

- 旧 Windows 便携版需手动下载并解压 v0.5.8 一次，之后即可使用应用内更新。保留 `portable.flag` 和 `tools`，程序目录必须可写。
- Windows 安装版、macOS 和 Linux AppImage 使用应用内更新；其他 Linux 包手动更新。Docker 用户拉取新版镜像并重新创建容器，保留原数据与下载目录。
- 重启安装会中断直播；普通下载按现有规则恢复，媒体处理可能重新开始。跨次启动复用更新包需要联网核对清单。
- macOS 仍要求 15 及以上，使用 ad-hoc 签名且未经 Apple 公证。

## In-app updates

- Desktop builds check after startup. The sidebar, About and Settings share update status, and downloads continue when switching pages.
- Choose **Download update**, follow download and signature-verification progress, then choose **Restart and install** when ready. Downloads and installation do not start automatically.
- Complete packages stay on disk. Reopening first checks the online manifest, then verifies and reuses a matching package without downloading it again.
- Installation stops background work, saves task progress and backs up configuration. A save or backup failure prevents installation and asks you to close and reopen the app.

## Windows portable updates and reliability

- Windows x64 / ARM64 portable builds download a signed ZIP. After the app exits, a helper replaces program files and bundled components, then starts the new version.
- Replacement failures restore previous files, and reopening can recover interrupted replacements. User files and custom files inside the tools folder are preserved.
- Managed components use Windows filename-case rules so old files cannot overwrite verified new components. Locked temporary files left after an update no longer prevent startup.
- Update manifests cover the six installer platforms and two Windows portable targets, while retaining installer targets used by older clients.

## Upgrade notes

- Older Windows portable builds need one manual download and extraction of v0.5.8 to gain in-app updates. Keep `portable.flag` and `tools`; the program folder must be writable.
- Windows installers, macOS and Linux AppImage use in-app updates. Update other Linux packages manually. Docker users should pull the new image and recreate the container while preserving data and downloads.
- Restarting for installation interrupts live captures. Regular downloads follow existing resume rules; media processing may restart. Reusing a package after reopening requires an online manifest check.
- macOS still requires version 15 or later and uses ad-hoc signing without Apple notarization.
