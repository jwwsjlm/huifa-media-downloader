## 组件更新与网站支持

- 桌面启动后自动检查 yt-dlp 稳定版和当前 JavaScript 运行时，有新版时提示，点击后才从官方上游下载并校验安装。
- 支持 Deno、QuickJS-NG 的远端版本查询和指定发行标签安装；FFmpeg 在“效率优先”策略下检查上游，“兼容优先”保持锁定构建。
- “新建下载”新增“查询网站支持”，输入域名或具体链接即可查询；粘贴单条链接后自动显示支持提示。
- 区分专用解析、通用解析和已知不支持的链接。没有专用匹配时仍可尝试视频直链或嵌入视频，下载遇到不支持的 URL 时显示明确说明。

## 性能与构建

- 增量同步直接读取未读事件，减少反复扫描历史记录；FFmpeg 更新后复用组件状态，减少重复版本查询。
- 桌面构建移除未使用的静态库和动态库产物，保留发行程序的优化设置；Windows 登录验证复用已验证的前端，发布归档不再重复压缩。
- 保留六个平台的原生验证、更新签名、Windows 便携版和双架构 Docker 镜像。

## 升级说明

- 组件更新只影响新任务；旧任务要使用新组件，可选择“使用当前设置重试”。内置抖音兼容插件随程序更新。
- 网站匹配不保证每条内容均能下载，登录及内容权限仍可能影响结果；仅凭域名无法确认时请提供具体视频链接。
- Docker 用户更新镜像并重新创建容器，保留原数据与下载目录。macOS 仍要求 15 及以上，使用 ad-hoc 签名且未经 Apple 公证。

## Runtime updates and website support

- Desktop startup checks stable yt-dlp and the current JavaScript runtime. New versions are announced; downloading and verified installation start only after you click.
- Deno and QuickJS-NG support remote version checks and exact release tags. FFmpeg checks upstream in Efficiency mode and keeps the pinned build in Compatibility mode.
- New download includes **Check website support**, and single pasted URLs receive automatic feedback from the installed extractors.
- Dedicated, generic and known unsupported matches are distinguished. Direct media and embedded videos can still use generic extraction; unsupported-URL failures show a specific explanation.

## Performance and builds

- Incremental synchronization reads only unread events, and FFmpeg updates reuse component status instead of repeating version checks.
- Desktop builds omit unused static and dynamic libraries while retaining production optimization. Windows login validation reuses the checked frontend; packaged release archives are uploaded without redundant compression.
- Native checks across six platforms, signed updates, Windows portable builds and dual-architecture Docker images remain in place.

## Upgrade notes

- Runtime updates apply to new tasks. Use **Retry with current settings** for existing tasks to adopt new components. The bundled Douyin compatibility plugin updates with the application.
- Extractor matching does not guarantee access to every video. Sign-in and content permissions still apply; provide a specific URL when a domain alone is inconclusive.
- Docker users should recreate containers from the new image while preserving data and downloads. macOS still requires version 15 or later and uses ad-hoc signing without notarization.
