# Huifa Media Downloader 0.1.2

## 中文

- 便携版升级为 Velopack 管理的目录结构，程序更新可整体替换 `current/`，同时保留根目录 `data/` 中的数据库、设置和浏览器登录状态。
- 便携版现在随包提供 FFmpeg、FFprobe、yt-dlp、Deno、yt-dlp-ejs 和 Playwright Chromium，新电脑完整解压后即可使用，无需安装 Python 或其他运行环境。
- 第三方运行组件支持在 `data/tools/` 中独立更新，并优先于软件随包提供的 `current/tools/` 保底版本。
- 便携版默认媒体目录调整为根目录 `downloads/`；安装版默认使用系统“下载”目录下的 `Huifa Video Downloader/`，避免媒体文件进入应用卸载范围。
- yt-dlp-ejs 现在严格匹配当前内置 yt-dlp 声明的固定版本；不兼容的 wheel 会被忽略并阻止安装，组件更新也会获取对应的配套 Release。
- GitHub Release 页面继续提供便携版 ZIP 和安装包 ZIP 的直接下载入口，并保留自动更新所需的完整包和版本元数据。
- 完善发布构建的真实更新验证，确认损坏的运行组件可以通过整目录更新恢复，同时便携数据保持不变。

## English

- The portable edition now uses a Velopack-managed directory layout. Application updates replace `current/` as a unit while preserving the database, settings, and browser sign-in state under the root `data/` directory.
- FFmpeg, FFprobe, yt-dlp, Deno, yt-dlp-ejs, and Playwright Chromium are bundled with the portable package, so a freshly extracted copy works without separately installing Python or other runtimes.
- Independently updated runtime components are stored under `data/tools/` and take precedence over the bundled fallback versions in `current/tools/`.
- Portable downloads now default to the root `downloads/` folder. Installed editions default to `Huifa Video Downloader/` under the system Downloads folder so media remains outside the application's uninstall scope.
- yt-dlp-ejs is now paired with the exact version declared by the bundled yt-dlp. Incompatible wheels are ignored and rejected during installation, and component updates resolve the matching EJS release.
- GitHub Releases continue to provide direct links for both the portable ZIP and installer ZIP while retaining the full packages and metadata required for automatic updates.
- Release validation now performs a real directory update recovery test, confirming that damaged runtime components are restored without removing portable user data.
