# Huifa Media Downloader 0.1.5

## 中文

- 修复 YouTube Mix 与合集条目只提供缩略图数组时列表不显示封面的问题。
- 修复分页合集搜索时过滤代理仍连接懒加载模型，可能造成界面卡死的问题。
- 避免缩略图更新触发无关的合集汇总查询。
- 移除未接入产品的图文发布类、二维码回调管线、一次性验证脚本和包导入副作用，净减少约 1,200 行代码。
- 全量 1,012 项自动化测试通过。

## English

- Fixed missing covers for YouTube Mix and collection entries that only provide a thumbnail array.
- Fixed a potential UI freeze when searching paged collections while the filter proxy remained connected to the lazy-loading model.
- Prevented thumbnail updates from triggering unrelated collection summary queries.
- Removed unused note publishers, QR callback plumbing, one-off verification scripts, and package import side effects, reducing the codebase by about 1,200 net lines.
- All 1,012 automated tests pass.
