# Huifa Media Downloader 0.1.12

## 中文

- 修复 `v0.1.11` MSI 安装向导打开时的 Windows Installer 错误 2810。
- 修正“选择安装范围”页面的控件导航顺序；“浏览目录”按钮现在可正常显示和使用。
- 保留自定义安装目录、Windows“已安装的应用”卸载项和自更新支持。

## English

- Fixed Windows Installer error 2810 when opening the MSI setup wizard in `v0.1.11`.
- Corrected the control navigation order on the installation-scope page; the Browse button now works normally.
- Custom install folders, Windows Installed apps uninstallation, and self-updating support remain available.
