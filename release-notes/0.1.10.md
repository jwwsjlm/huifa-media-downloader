# Huifa Media Downloader 0.1.10

## 中文

- 修复检查程序更新时可能出现的 GitHub HTTP 403：稳定版改为直接读取 GitHub Release 的静态 Velopack 更新清单，不再消耗 GitHub REST API 配额。
- 不需要独立下载域名；更新清单和安装包仍由项目的 GitHub Release 提供。
- 预发布和指定更新通道继续使用 GitHub API，以保留对应的发布筛选能力。

## English

- Fixed possible GitHub HTTP 403 errors while checking for application updates: stable releases now read the static Velopack update feed from GitHub Releases instead of consuming GitHub REST API quota.
- No separate download domain is required; the update feed and packages remain hosted on this project's GitHub Releases.
- Prerelease and explicit update-channel checks continue to use the GitHub API to preserve their release filtering behavior.
