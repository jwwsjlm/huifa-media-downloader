# Huifa Media Downloader 0.1.11

## 中文

- 安装版改为 Windows Installer（MSI）：启动后显示安装向导，不再直接安装。
- 安装向导支持选择“当前用户”或“所有用户”，并可浏览并指定自定义安装目录。
- 安装后会在 Windows“已安装的应用”中登记标准卸载项；可从系统设置正常卸载。
- 面向用户的安装包 ZIP 内现在提供 `HuifaMediaDownloader-Setup.msi`。

## English

- The installed edition now uses Windows Installer (MSI), which opens an installation wizard instead of installing immediately.
- The wizard supports per-user or all-users installation and lets users browse to a custom installation folder.
- Installation registers a standard uninstall entry in Windows Installed apps, so it can be removed through system settings.
- The user-facing installer ZIP now contains `HuifaMediaDownloader-Setup.msi`.
