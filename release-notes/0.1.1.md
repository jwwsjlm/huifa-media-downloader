# Huifa Media Downloader 0.1.1

## 中文

- GitHub Release 现在同时提供 Windows x64 便携版 ZIP 和安装包 ZIP。
- 安装版使用 Velopack 管理安装目录，并保留后续自动更新所需的更新 feed 和完整包。
- 便携版继续使用单文件程序，解压后即可运行，原有本地 `data/` 数据目录保持不变。
- GitHub Release、程序更新界面和安装版更新包现在共用同一份版本说明。
- 项目首页新增独立的中文与英文 README，并加入真实软件界面截图。

## English

- GitHub Releases now provide both a Windows x64 portable ZIP and an installer ZIP.
- The installed edition uses Velopack to manage its installation and includes the feeds and full packages required for future updates.
- The portable edition remains a single-file application inside the ZIP and continues to use its adjacent `data/` directory.
- GitHub Releases, the in-app update dialog, and installed-edition update packages now share the same release notes.
- The project now has separate Chinese and English README files with a real application screenshot.
