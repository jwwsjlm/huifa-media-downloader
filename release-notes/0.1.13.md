# Huifa Media Downloader 0.1.13

## 中文

- 安装包改为传统的 HuifaMediaDownloader-Setup.exe 向导，安装前可明确选择安装目录。
- 向导在所选目录中调用内部安装组件，保留 Windows“已安装的应用”卸载项和 Velopack 自动更新。

## English

- The installed edition now uses the traditional HuifaMediaDownloader-Setup.exe wizard, which explicitly lets you choose the installation folder before installation.
- The wizard installs the internal package into the selected folder while retaining the Windows Installed apps uninstall entry and Velopack automatic updates.
