# 0.3.0

- 新增桌面与 Docker/NAS MCP 服务，提供视频资料、格式、合集、字幕、YouTube 评论和下载队列工具；管理页与协议地址分离，单开关控制服务。
- 增强多站点资料处理：字幕轨道发现支持 JSON3、VTT、SRT，Bilibili 分 P 链接保留 `p` 参数；不支持有界评论的站点会明确返回原因。
- 修复 Docker MCP 关闭时在途查询和旧会话未停止的问题，并补齐 Host/Origin、协议和生命周期回归测试。
- 统一提供包含运行时工具的 Windows 安装包和便携 ZIP，均包含 MCP 桥接程序，并保留签名和 SHA-256 发布门禁。
- 更新 README、Docker/MCP 使用说明和真实 Docker 界面截图；CI 使用 Node.js 24 并覆盖 MCP 测试与桥接程序构建。

YouTube 等站点可能要求有效登录 Cookie；站点限流、地区限制和代理策略仍由 yt-dlp 决定。
