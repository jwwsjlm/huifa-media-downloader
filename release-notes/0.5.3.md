## 下载稳定性与界面统一

- 修复部分视频解析成功后下载仍卡住的问题，下载沿用已解析的媒体地址，避免重复查询切换 CDN 后超时。
- 改进 Windows 启动失败提示，显示错误日志位置，并提供启动诊断脚本，便于定位双击后退出的问题。
- 统一深浅主题下的按钮、输入框、选项切换、卡片、弹窗、错误提示和展开箭头，完善悬停、禁用及键盘焦点状态。
- 修复窄屏设置标签拥挤和弹窗宽度问题，统一浏览器导航图标，保留原生登录窗口的工具栏尺寸。
- 补充下载与 Windows 启动回归检查，修正原生浏览器测试中关闭窗口后的等待时序。

## Download stability and consistent interface

- Fixed downloads that could stall after successful media lookup. Transfers reuse the resolved media URLs instead of repeating extraction and potentially switching to an unreachable CDN.
- Improved Windows startup failure messages with an error-log location and a diagnostic script for applications that exit immediately after launch.
- Unified buttons, form fields, option selectors, cards, dialogs, error notices and disclosure arrows across light and dark themes, including hover, disabled and keyboard-focus states.
- Fixed crowded settings tabs and dialog widths on narrow screens. Browser navigation uses consistent icons while preserving the native sign-in toolbar dimensions.
- Added download and Windows startup regression checks and corrected the shutdown wait in the native browser test.
