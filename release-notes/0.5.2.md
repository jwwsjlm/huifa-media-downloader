## 稳定性与媒体兼容性修复

- 修复通过局域网 HTTP 地址访问 Docker/NAS 时无法添加下载的问题，自动识别、合集选择和手动格式选择均支持该访问方式。
- 修复最高画质视频没有独立音轨时丢失声音的问题，可从包含音视频的备用格式中补充音频。
- 修复 WebM 裁剪、SponsorBlock 去除、封面片头和章节拆分使用不兼容编码的问题；修复 MOV 嵌入字幕失败。
- 修复取消章节导出或准备阶段失败后遗留隐藏发布文件的问题，任务登记完成前保留自动清理。
- 为普通视频与合集信息查询增加读取大小和总超时限制，保留原始任务日志、取消操作和明确启用的等待直播行为。
- 修复状态同步期间再次丢失事件后任务状态未刷新的问题。
- 修复桌面端“关于”页面项目链接的命令权限，补齐 MCP 任务警告中的本地路径隐藏处理。
- 补充局域网访问、音轨选择、媒体编码、取消清理、查询限制和事件同步回归测试，修复版本显示测试的偶发时序失败。

## Stability and media compatibility fixes

- Download creation now works through plain HTTP LAN addresses in Docker/NAS, including automatic detection, collection selection and manual format selection.
- Video-only quality selections keep available audio from a combined video/audio format when no separate audio stream exists.
- WebM cuts, SponsorBlock removal, cover intros and chapter exports use compatible codecs. MOV subtitle embedding uses the supported subtitle codec.
- Cancelled or failed preparation cleans staged publication files until the task has durably recorded them.
- Ordinary video and collection queries have bounded output and an overall timeout, while preserving raw task logs, cancellation and explicit live waiting.
- Repeated resync requests during a pending snapshot trigger another refresh, so missed completion events do not leave stale task state.
- The desktop About project link has its required command permission. MCP task warnings now hide internal paths consistently with errors.
- Added regression checks for these workflows and removed a timing race from the packaged-version test.
