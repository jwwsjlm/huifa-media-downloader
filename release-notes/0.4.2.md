# Huifa Media Downloader 0.4.2

## 下载与任务
- 下载大小栏显示累计已下载字节；已知总大小时同时显示总量，估算值使用 `≈`。视频与音轨分开下载时累计显示，完成后显示最终文件大小。
- 任务列表支持 Shift 连选、Ctrl 切换、Ctrl+A 和全选当前筛选结果，并可批量删除；删除前确认是否同时删除受管媒体文件，部分失败可单独重试。
- 首次进入、返回任务页、重连或收到后台进度时，不再自动选中任务；手动点选和重复任务定位正常保留。
- 下载设置增加保存目录选择并立即持久化。新建或重新添加的下载使用新目录，已有任务和文件保持原目录。
- 任务列表增加封面缩略图，与已完成媒体库共用右键菜单，支持查看日志、复制名称／来源／完整路径、转换和删除。
- 高帧率结果显示 `1080p60`、`4K60` 等画质标记；详情保留精确帧率。修复已结束直播回放被“仅非直播”筛选误排除的问题。

## 日志与界面
- 任务日志记录 yt-dlp 原始调用参数、标准输出、错误输出和进度，支持分页、自动刷新与复制完整日志。旧任务无法补回此前未记录的输出。
- 日志可能包含认证信息、Cookie、本地路径和临时媒体地址，分享前请检查。原始日志只通过已鉴权的任务日志接口读取，不进入普通快照或 MCP 工具结果。
- 新建下载的方案与画质移到标题行，减少面板高度；调整任务详情操作按钮和“关于”页间距。
- 底栏显示所有下载任务的总速度；失败、取消及完成的任务显示最终状态，避免残留工序编号和名称。
- 修复启动时版本号闪回旧值及同步工具检查造成的卡顿。GitHub API 限流时，版本检查可通过本项目官方发行页面确认新版本，并显示具体失败原因。

## 下载与部署
- 提供 Windows 安装版、签名便携 ZIP、Linux AppImage，以及 Docker `linux/amd64` 和 `linux/arm64` 镜像。
- Docker Compose 使用 `ghcr.io/jwwsjlm/huifa-media-downloader:latest`，数据和下载映射使用 `./data` 与 `./downloads`。本版另提供固定标签 `0.4.2`。
- 保留现有配置、任务、Cookie 和下载文件。Docker 升级执行 `docker compose pull` 和 `docker compose up -d`，保留原有数据卷；便携版不自动安装更新。
- 发布流程检查前端、Windows／Linux 原生下载与处理、Docker 双架构认证和持久化，并验证签名及校验和后发布。
