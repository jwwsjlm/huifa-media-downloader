# Huifa Media Downloader 0.1.16

## 中文

- 安装向导默认目录改为 `C:\Program Files\Huifa_Media_Downloader`：保留在 Windows 的 Program Files 目录下，同时软件文件夹名称不含空格。仍可在向导中选择其它安装位置。

## English

- The installer now defaults to `C:\Program Files\Huifa_Media_Downloader`: it stays under Windows Program Files while the application folder itself contains no spaces. A different location can still be selected in the wizard.
