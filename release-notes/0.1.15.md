# Huifa Media Downloader 0.1.15

## 中文

- 安装向导的默认目录改为 `C:\Huifa_Media_Downloader`（系统盘），完整默认路径不再包含空格；仍可在向导中选择其它安装位置。

## English

- The installer now defaults to `C:\Huifa_Media_Downloader` on the system drive, so the complete default path contains no spaces. A different location can still be selected in the wizard.
