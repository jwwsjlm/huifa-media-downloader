# Huifa Media Downloader 0.1.6

## 中文

- 默认打包并推荐使用固定的 2026-05-31 FFmpeg 兼容构建，提高较旧 NVIDIA 驱动与 NVENC API 13.0 的兼容性。
- 保留 FFmpeg 滚动最新版选项，可在设置中手动切换。
- 修复 GitHub 更新元数据返回 403 或 429 时直接显示 HTTP 错误的问题，现会自动降级到公开 Release 页面继续检查。
- 为默认 FFmpeg 通道、固定发布资产和无速率限制响应头的 403 降级增加回归测试。
- 全量 1,013 项自动化测试通过。

## English

- Bundles and recommends the pinned May 31, 2026 FFmpeg compatibility build by default for older NVIDIA drivers and NVENC API 13.0.
- Keeps the rolling latest FFmpeg build available as an optional setting.
- Fixed update checks exposing raw HTTP 403 or 429 errors by falling back to the public GitHub Release page.
- Added regression coverage for the default FFmpeg channel, pinned release asset, and 403 fallback without rate-limit headers.
- All 1,013 automated tests pass.
